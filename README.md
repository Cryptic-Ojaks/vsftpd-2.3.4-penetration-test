# vsftpd 2.3.4 Backdoor – Penetration Testing Lab

## Overview

This project demonstrates the exploitation of the **vsftpd 2.3.4 backdoor vulnerability** in a controlled cybersecurity laboratory environment.

The project uses **Kali Linux** as the attacker machine and **Metasploitable 2** as the intentionally vulnerable target.

The purpose of this project is to demonstrate the process of identifying a vulnerable service, researching the associated vulnerability, performing an authorized exploitation attempt, verifying access, assessing the potential security impact, and recommending remediation.

> **Disclaimer:** This project was performed exclusively in an authorized, isolated laboratory environment for educational and cybersecurity training purposes.
